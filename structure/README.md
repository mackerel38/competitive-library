# structure

競技プログラミングで使うデータ構造を置きます。

- `dsu.hpp`: Disjoint Set Union
- `fenwick_tree.hpp`: Fenwick Tree
- `fenwick_tree_2d.hpp`: 2D Fenwick Tree
- `segtree.hpp`: Segment Tree
- `lazy_segtree.hpp`: Lazy Segment Tree
- `dual_segtree.hpp`: Dual Segment Tree
- `sparse_table.hpp`: Sparse Table
- `rollback_dsu.hpp`: Rollback DSU
- `swag.hpp`: Sliding Window Aggregation
- `binary_trie.hpp`: Binary Trie
- `wavelet_matrix.hpp`: Wavelet Matrix
- `hashmap.hpp`: custom hash map / set aliases
- `simple_treap.hpp`: simple implicit Treap
- `treap.hpp`: implicit Treap with lazy propagation and reverse
